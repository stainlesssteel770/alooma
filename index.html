Settings

Editor access on this device

How to make a token (one time, ~2 minutes)
  1. On github.com, click your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Name it "Alooma editor", set an expiration you're comfortable with.
  3. Repository access: Only select repositories → pick alooma.
  4. Permissions → Repository permissions → Contents → Read and write. Leave everything else off.
  5. Generate, copy the token, and paste it here. It is saved only on this device — never in the repo, never on the site.

Disconnecting removes the saved token from this device only. The site goes back to view-only here; your data in the repo is untouched.

Backup

Export downloads everything (inventory + history) as one file. Import replaces the current data with a backup file (editor only) and is logged in History.

About

Data lives in data.json in the public GitHub repo stainlesssteel770/alooma. Every edit commits a new version of that file through the GitHub API, so any device opening this page sees the current status. Viewers need no sign-in. There is no access code.
